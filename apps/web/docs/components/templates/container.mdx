# Container

Centers page content at a capped width with consistent responsive gutters — the standard `mx-auto max-w-* px-*` wrapper in one place. Use `asChild` to merge the styling onto your own element instead of rendering an extra `div`.

```tsx
import { Container } from '@jbpark/ui-kit';

<Container maxWidth="md">Page content</Container>;
```

## Props

| Prop        | Type                                          | Default |
| ----------- | --------------------------------------------- | ------- |
| `maxWidth`  | `'3xs'`…`'7xl'` \| `'full'` \| `'none'`        | `'7xl'` |
| `padded`    | `boolean` (responsive horizontal gutters)      | `true`  |
| `asChild`   | `boolean` (merge onto the child element)       | `false` |
| `className` | `string`                                       | -       |

`maxWidth` accepts Tailwind's full `max-w-*` scale. All other `div` props are forwarded.
